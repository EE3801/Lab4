# Part 3. Creating bash scripts for checking outputs and deleting files

## 8.
In order to make it easier to check the outputs of your jobs, we will write a shell script to perform the commands from Step 35 in Lab 2:

> [Headnode & in PyHipp directory]
>```shell
>nano checkfiles.sh
>```

Copy and paste the following into the script:

```bash
#!/bin/bash

echo "Number of hkl files"
find . -name "*.hkl" | grep -v -e spiketrain -e mountains | wc -l

echo "Number of mda files"
find mountains -name "firings.mda" | wc -l

echo "Time taken (s)"
tail pipe-slurm*.out
```

## 10.
We will also create a shell script to remove the files created during the last run:

> [Headnode & in 20181105 directory]
>```shell
>cd -
>
>nano removefiles.sh
>```

The "cd -" command changes directory to the previous directory, which in this case was "/data/src/PyHipp". Copy and paste the following into the script:

```bash
#!/bin/bash

find . -name "*.hkl" -or -name "*.csv" | xargs rm

find . -name "*slurm*err" -or -name "*slurm*out" | xargs rm

rm -r mountains

cd session01

rm binData.hdf logs.txt slist.txt VirtualMaze*

cd ..
```

>```

The "cd -" command changes directories to the previous directory, which was "/data/picasso/20181105". Run the checkfiles shell script again to check that the files have been removed.
